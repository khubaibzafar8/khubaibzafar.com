# Khubaib Zafar — Professional Website

Responsive multi-page static website with distinct organisational branding, dedicated enquiry/volunteer forms, and a Decap CMS starter for News, Scholarships/Special Calls and EduWisers destination management.

## Included pages
- `index.html` — personal profile, education, publications and navigation
- `speaking.html` — public speaking profile
- `upg.html` — UPG Sustainability Leadership
- `kb-hortica.html` — services, Ghar Ghar Bagh membership, project gallery placeholder and quotation enquiry
- `climate-change-combat.html` — C³ think tank and volunteer form
- `pic.html` — PIC profile, wings, initiatives and volunteer form
- `jhang-youth-alliance.html` — Jhang-specific volunteer/member form
- `the-eduwisers.html` — study destinations, services and profile assessment enquiry
- `news.html` — regular news and newsletter page
- `scholarships.html` — scholarship and special calls page

## Deployment (free static hosting option)
1. Create a GitHub repository and upload the contents of this folder.
2. Connect the repository to Netlify and deploy the site.
3. In Netlify, enable **Identity** and **Git Gateway**, invite your account, and accept the invitation.
4. Update `admin/config.yml` with the deployed Netlify URL and repository branch if required.
5. Visit `/admin/` on your deployed website to manage News, Scholarships/Special Calls and EduWisers destinations.
6. In Netlify Forms, enable notifications and test each form after deployment.

## Important setup notes
- The forms are Netlify Forms-compatible, but submissions are not live until deployed to Netlify and tested.
- The CMS requires a Git repository and Netlify Identity/Git Gateway setup; this is not activated by the ZIP alone.
- The public News and Scholarships pages are currently ready as landing pages; CMS entries need a connected content-rendering workflow before posts automatically appear there. The CMS collections are configured as a starting point.
- Add your formal portrait, speaking photos, KB Hortica project images and organisational activity photographs to replace gallery placeholders.
- Social links currently include LinkedIn, Instagram and Facebook. Freelancer has been removed. TikTok can be added when the username is supplied.
- This package is a first deployable design/content version. Please verify wording, contacts and event dates before publishing publicly.
